# T-0839 — Give remediation verify a worker entrypoint

## Report

`POST /v1/remediation/actions/:actionId/verify` enqueues a `remediation` job with `operation: "verify"`, and
`createRemediationQueue` refuses it with 501. `M365Portal.Workers/Invoke-RemediationVerify.ps1` defines the
verify logic, but there is no entrypoint script under `portal/workers/` that reads a job file, runs it, and
writes a result envelope, and nothing stores its outcome on the action.

## Acceptance

- [ ] A verify entrypoint reads the job file and writes `result.json`.
- [ ] The remediation dispatcher runs it for `operation: "verify"`, and the outcome is stored on the action.
- [ ] The 501 for verify is removed.
