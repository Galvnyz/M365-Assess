# T-0837 — Run custom scripts in the sandbox

## Report

`POST /v1/scripts/:scriptId/run` (T-0127) runs a script version through a `ScriptSandbox` seam over the
T-0126 sandboxed runner (`Invoke-SandboxedScript`). There is no worker entrypoint for it, and the
T-0126 Pester suite has nine failing tests. T-0824 mounts the scripts routes with a sandbox that
refuses with 501 `scripts.sandbox_unavailable`.

Add a feature-worker entrypoint that runs one script version in the sandbox for a tenant (dry run
honoured only for scripts with the dry-run contract), and a `ScriptSandbox` adapter on
`runFeatureWorker`.

## Acceptance

- [ ] The T-0126 sandbox tests pass.
- [ ] A worker entrypoint runs a script version in the sandbox and returns output, exit code, and duration.
- [ ] The scripts run route uses it; the 501 port is removed.
