# T-0840 — Run scheduled jobs: run-now, the scheduler tick, and run records

## Report

Schedule run-now still refuses with 501 (`createUnavailableScheduleQueue`), and nothing starts the tick
(`scheduler/tick.ts`, `tickSchedules`), so due schedules never run. T-0836 added the job dispatcher; what
scheduled jobs still need:

- `buildScheduledEnvelope` creates assessment, standards, drift, and report envelopes with no run record and
  no `context.json`. Assessment runs need both (see `createRunQueue`); the other types need a runner
  registered with the dispatcher (`createJobDispatcher`), and report jobs depend on T-0835.
- Something must start and stop the tick with the app, and record outcomes (`recordScheduleOutcome`).
- Schedule history finds a schedule's jobs by their `schedules/<id>/` refs; keep that working or store
  the schedule id on the job.

## Acceptance

- [ ] Run-now and the tick enqueue scheduled assessment runs with run records and context files.
- [ ] Job types with no runner are refused when the schedule is saved or run, not failed silently later.
- [ ] The tick starts and stops with the app; schedule history reflects runs.
- [ ] The run-now 501 is removed for the types that can run.
