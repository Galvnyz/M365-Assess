# T-0834 — Remove the superseded EPIC-001 run routes

## Report

`routes/runs.ts` (EPIC-001, T-0011) serves run detail, results, artifact download, and cancel on the
same paths as the EPIC-003 modules (`runs-detail.ts`, `runs-artifacts.ts`, `runs-actions.ts`), plus
`POST /v1/tenants/:tenantId/runs`, which duplicates `POST /v1/runs`. The web app uses only the EPIC-003
paths, and T-0821 mounts only the EPIC-003 modules. The module and its tests are dead code that still
has to be kept compiling.

Move anything still used elsewhere (for example `createFileArtifactReader`, if referenced) and delete
the module and its tests.

## Acceptance

- [ ] `routes/runs.ts` and `routes/runs.test.ts` are gone, or kept only for helpers something else imports.
- [ ] No mounted route or test depends on them.
