# T-0224 — Send push notification and set default MFA method

## Report

EPIC-012 SPEC.md §3.2 (US-4, US-5): **Send push** targets a registered device, and **Default
method** selects from the user's registered methods. §4.2 routes both through EPIC-006 (confirm,
apply, audit).

Add `POST /v1/tenants/{id}/users/{userId}/push` and
`POST /v1/tenants/{id}/users/{userId}/default-method` to `mfa.ts`, and the
`Invoke-MfaAction.ps1` worker job plus `invoke-mfa-action.ps1` entrypoint. Setting a default
method is rejected when the requested method is not in the user's registered set; sending a push
is rejected when no push-capable device is registered. Both actions are audited.

## Acceptance

- [x] Push is sent only to a registered device and the result is reported.
- [x] Default method is accepted only from the registered set; an unregistered method returns a structured 4xx.
- [x] Both actions route through EPIC-006 and write an `AuditEvent`.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
