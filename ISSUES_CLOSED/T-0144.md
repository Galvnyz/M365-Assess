# T-0144 — Standards catalog API and licence gating

## Report

EPIC-008 SPEC.md §4.4 (US-6): before applying, each standard checks the tenant's licences against
`src/M365-Assess/controls/licensing-overlay.json` and the registry `licensing.minimum`. A missing
licence results in state `license missing` and is **skipped, not failed** (CIPP's
`Test-CIPPStandardLicense` model). §6 adds `GET /v1/standards/catalog` listing available
standards for the picker.

Deliver the catalog endpoint and `standards-license.ts`, which resolves the tenant's licence set
and classifies each standard as eligible, `license missing`, or unknown-licence. The classification
is consumed by the template builder and the execution worker (T-0145).

## Acceptance

- [x] `GET /v1/standards/catalog` returns the standards with category and licence metadata.
- [x] A standard needing a licence the tenant lacks is classified `license missing`, not failed.
- [x] An unrecognised `licensing.minimum`/overlay entry is surfaced explicitly rather than silently passing.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
