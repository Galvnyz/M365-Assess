# T-0146 — Standards templates list UI

## Report

EPIC-008 SPEC.md §3.1 defines the **Standards Templates** page: a `DataTable` with Name · Type
(`standards`/`drift`) · Assigned to · Standards count · Schedule · Last run, filters by type,
assigned target, and schedule, and a `Create template` primary button. Row actions are
`View tenant report`, `Edit`, `Clone & edit`, `Create drift clone`, `Run template now` (with
confirm), `Set schedule`, `Save to GitHub` (only when EPIC-039 is enabled), `Delete`, and
`Convert`. US-1, US-4, and US-8 ride on this surface.

Deliver the list route, `TemplatesTable`, and the typed `standardsApi.ts` client wired to the
T-0143 endpoints. Use report theme tokens only, no colour literals. The drift-clone and
GitHub-save actions call into EPIC-009/EPIC-039 (prose cross-refs).

## Acceptance

- [x] The table renders every §3.1 column and supports the named filters.
- [x] Row actions are present; `Save to GitHub` is hidden unless the GitHub integration is enabled, and `Set schedule` is hidden for drift templates.
- [x] A test covers the table states and fails without it; only theme tokens are used.
- [x] No file outside `scope` is modified.
