# T-0309 — Assignment filters: CRUD, templates, and deploy

## Report

EPIC-016 SPEC.md §3.3 defines **Assignment Filters** — a list plus templates, with a deploy
wizard to target tenants. §5 adds `AssignmentFilterTemplate` (`id`, `name`, `platform`, `rule`,
`source`); §6 fixes `GET`/`POST /v1/tenants/{id}/intune/assignment-filters`. §9 warns of
assignment drift (CIPP's `Compare-CIPPIntuneAssignments`); filters are the building block that
compare (T-0310) inspects.

Deliver `Set-AssignmentFilter.ps1` + entrypoint, the `AssignmentFilterTemplate` migration and
BFF routes behind the T-0108 gated-write seam, and `AssignmentFilterTable` (list + template deploy
wizard). The rule string is validated against the standard filter rule grammar and `platform` is
validated against the T-0301 registry. Each write is audited with before/after.

## Acceptance

- [x] Assignment filters support create, edit, and delete with before/after audit.
- [x] Filter templates persist and can be deployed to one or more tenants via the wizard.
- [x] Rule strings and platforms are validated and invalid input is rejected with a structured error.
- [x] Tests cover the route, worker, and component and fail without them.
- [x] No file outside `scope` is modified.
