# T-0242 — PIM eligible/active view and Entra ID P2 license gate

## Report

EPIC-013 SPEC.md §3.1 and §9 (US-2): the **PIM** tab shows eligible and active assignments and,
when Entra ID P2 is unavailable, shows a **P2-license gate that explains the requirement** rather
than failing or hiding the tab. §11.4 resolves the gate UX to **explain (CIPP's license-missing
pattern).** §6 exposes `GET /v1/tenants/{id}/pim`.

Add the BFF route to `pim.ts` with a `license-gate.ts` that classifies P2 availability from the
tenant's licenses (and returns a structured `license-missing` state), plus the read-only
`Get-PimAssignments.ps1` worker job and `get-pim-assignments.ps1` entrypoint returning eligible
and active assignments. A non-PIM (no P2) tenant returns the explanatory gate payload, not an
error; the assignments view remains usable. Extend `portal.v1.yaml`.

## Acceptance

- [x] `GET /v1/tenants/{id}/pim` returns eligible and active assignments when P2 is present.
- [x] Without P2 the response is a structured gate payload with a clear explanation, not a failure.
- [x] The worker is read-only and the BFF route holds no M365 SDK call.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
