## Report

EPIC-010 SPEC.md §3.1 (US-4) defines **Baselines — Fleet Overview**: a first-run welcome card,
**Deviation States** counts (shared vocabulary with EPIC-009), a **Tenants Needing Attention**
table (open deviations / stalled stages), and **Accepted & Denied Deviations** summary. §3.2
defines the **Baselines** list with Name · Stages · Assigned tenants/groups · Fleet compliance ·
Last run and row actions `View`, `Edit`, `Run now`, `Delete`, `Export`; primary button

`GET /v1/baselines/fleet`.

Deliver the fleet endpoint, the baselines list page, and `FleetOverview`. The **Fleet Compliance
Trend** chart is contributed by T-0188 (prose cross-ref); this ticket leaves a container for it.
