# T-0168 — Manage Drift UI and triage dialogs

## Report

EPIC-009 SPEC.md §3.1 defines **Manage Drift — <tenant>**: a breakdown `.kpi-strip` by state, a
filters card (state, standard/category, resource type, severity), bulk actions
(`Accept`, `Denied-Delete`, `Denied-Remediate`), primary buttons (`Refresh data`,
`Generate report`, `Edit template`, `Run standard now`), a `DataTable` (Standard/Property (mono),
Current, Expected, `status-badge` State, Reason, Expires, Last seen), and a row detail drawer with
history and triage actions. §3.2 defines the triage dialogs; the deny dialog must show the
**destructive warning verbatim** and require explicit confirmation.

Deliver the page, `DriftTable`, `DriftDialogs`, and the typed `driftApi.ts` client wired to
T-0164/T-0165/T-0166/T-0167. The `Move to next stage` dialog belongs to EPIC-010 (prose). Use
theme tokens only.

## Acceptance

- [x] The breakdown, filters, table, and row drawer render from the T-0164 API.
- [x] Triage dialogs call the accept/override/deny endpoints; the deny dialog shows the verbatim warning and blocks on cancel.
- [x] Bulk actions submit through the T-0167 endpoint; a test covers the dialog states.
- [x] No file outside `scope` is modified.
