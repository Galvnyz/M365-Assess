# T-0826 — Feature workers connect to their tenant

## Report

Every feature worker (34 entrypoints under `portal/workers/`) calls `Invoke-MgGraphRequest`, and
three also use Exchange Online cmdlets, but none connects first: only the assessment path
(`run-tenant.ps1` → `Invoke-M365Assessment`) signs in. `Resolve-TenantCredential` (T-0011)
already turns a credential reference plus its non-secret row into auth material inside the child
process, and `Test-TenantConnection` shows the connect pattern through the module's
`src/M365-Assess/Common/Connect-Service.ps1`.

Add `Connect-WorkerTenant`: read the job file's `credential` block (`credentialRef` and the
non-secret `record` the BFF includes), resolve it with `Resolve-TenantCredential`, connect the
services the worker declares (Graph by default; Exchange Online for the three EXO workers) via
`Connect-Service.ps1`, and return a disconnect action. Every Graph/EXO entrypoint connects after
reading its job and disconnects in `finally`. Errors are coded and never contain secret material
(`Protect-WorkerSecret`). A job without a `credential` block fails with a clear code rather than
running unauthenticated. Secret-backed credentials still need T-0827's backend; thumbprint
credentials work without it.

## Acceptance

- [x] `Connect-WorkerTenant` resolves the job's credential and connects the requested services, returning a disconnect action.
- [x] Every Graph- or EXO-calling feature entrypoint connects before work and disconnects in `finally`.
- [x] Missing or mismatched credential blocks fail with a coded error; secrets never appear in messages.
- [x] Pester tests cover the function (with Connect-Service and the resolver mocked) and a convention check over the entrypoints, and fail without the change.
- [x] No file outside `scope` is modified.

## Resolution

- `Connect-WorkerTenant` / `Disconnect-WorkerTenant` / `Read-WorkerCredentialBlock` in
  `M365Portal.Workers/Connect-WorkerTenant.ps1`; Exchange Online requests pass the `Email` section so
  the resolver's client-secret rejection applies.
- 34 entrypoints connect when run with `-JobFile` and disconnect in `finally`
  (`set-group-gal-delivery` uses Exchange Online only; `invoke-bec-check` and
  `invoke-user-offboarding` use Graph and Exchange Online). `-ByParams` runs manage their own session.
- `get-bitlocker-keys.ps1` and `get-laps-credentials.ps1` gained a `-JobFile` parameter set.
- Not connected: `plan-remediation`, `get-remediation-instruction`, and `render-report` make no tenant
  calls. `apply-remediation` connects Graph only; remediation commands that need SharePoint Online
  have no connect path in `Connect-Service.ps1` yet.
- Also updated (fallout outside scope): `tests/Portal/Defender/CveExceptions.Tests.ps1` for the T-0816
  permission rename, and the CA/Intune policy entrypoint tests to stub the tenant connection.
