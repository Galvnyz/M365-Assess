# T-0269 — Hide-from-GAL and delivery management via EXO

## Report

EPIC-014 SPEC.md §3.4 defines `ActionDialog`s for hide-from-GAL and delivery management (sender
authentication, send-on-behalf) using **EXO**; §4.4 requires those EXO-backed writes to be gated
and audited via EPIC-006; §6 fixes `POST .../gal` and `POST .../delivery`. §7 adds the EXO tenant
auth requirement, and §9 warns that GAL/delivery requires an EXO session (mutual exclusion with
Purview) handled by the per-tenant process model.

Deliver `Set-GroupGalDelivery.ps1` + entrypoint, the BFF routes behind the T-0108 gated-write
seam, and the two `GalDeliveryDialog` flows. The worker runs inside the per-tenant child process
so the EXO session is isolated and serialized with Purview, applies the change, captures
before/after, and audits each write. Invalid delivery-management combinations (e.g. send-on-
behalf without a grant) are rejected with a structured error before apply.

## Acceptance

- [x] Hide/show GAL and delivery management apply through an EXO session in the per-tenant child process.
- [x] Each change is confirmed, before/after captured, and audited; invalid combinations are rejected.
- [x] Tests cover the route and dialog and fail without them.
- [x] No file outside `scope` is modified.
