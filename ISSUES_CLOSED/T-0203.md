# T-0203 — Bulk patch wizard API and diff preview

## Report

EPIC-011 SPEC.md §3.3 and §4.2 (US-3): the patch wizard selects users, chooses properties, sets
values, and shows a **preview diff** before apply; each change is planned and audited. Build
`portal/bff/src/domain/users/patch.ts` to compute the per-user before/after diff for the chosen
property set (only changed rows appear), and add `POST /v1/tenants/{id}/users/bulk-patch` to
`users.ts` with a `preview` mode that returns the diff and an apply mode that runs each patch
through the EPIC-006 gated executor (T-0107).

The `Set-TenantUserProperties.ps1` worker job plus `set-tenant-user-properties.ps1` entrypoint
apply the planned patches; results are per row and every applied change records before/after and
an `AuditEvent`. A preview call must make no tenant write.

## Acceptance

- [x] `preview` returns a per-user diff of only the properties that would change, with no tenant write.
- [x] Apply routes each row through the EPIC-006 gate/executor and records before/after plus an audit record.
- [x] A row that becomes invalid between preview and apply is reported as a per-row failure, not silently skipped.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
