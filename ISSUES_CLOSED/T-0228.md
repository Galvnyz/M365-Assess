# T-0228 — MFA report page with KPI strip, table, and filters

## Report

EPIC-012 SPEC.md §3.1 (US-1): page title **MFA Report**; a **KPI strip** (total users,
MFA-registered, not-registered, phishing-resistant, per-method counts), a table (User · UPN ·
Methods registered · Default method · Phishing-resistant? · Last auth · State), filters
(registered/not, method, phishing-resistant, license, admin role), row actions (`Reset MFA`,
`Require re-registration`, `Send push`, `Set default method`, `Create TAP`, `View user`), and
bulk actions (require re-registration, send push).

Build the route and `MfaReportTable` plus `MfaKpiStrip`, and a typed `mfaApi.ts` client for the
T-0221 endpoint. Row/bulk actions for reset, push, and default method delegate to the dialogs
built in T-0229; while T-0229 is not yet present, render them disabled with a reason. Use report
theme tokens only.

## Acceptance

- [x] The KPI strip and table render the T-0221 payload; each filter narrows the rows.
- [x] Bulk actions are only enabled when at least one row is selected; selection count is shown.
- [x] `Send push`, `Reset MFA`, and `Set default method` are wired or disabled with a reason.
- [x] Only report theme tokens/classes are used; no colour literals.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
