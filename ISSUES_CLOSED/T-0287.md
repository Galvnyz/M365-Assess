# T-0287 — CA templates page and deploy drawer

## Report

EPIC-015 SPEC.md §3.2 fixes the **CA Templates** page (row actions `View`, `Edit`, `Clone`,
`Deploy`, `Delete`, `Export`) and the **deploy drawer** with CIPP `CippCADeployDrawer` parity:
template pick · group/user handling radio · policy state radio · overwrite switch ·
disable-security-defaults switch · create-groups toggle, showing a plan before apply.

Build the page, `CaTemplateTable`, and `CaDeployDrawer` against the T-0285/T-0286 APIs. The
drawer defaults the state radio to **report-only** and renders an explicit callout when
*disable security defaults* is selected. It shows the returned plan (policies + group actions)
and per-policy results.

## Acceptance

- [x] Templates can be viewed/edited/cloned/deployed/deleted/exported.
- [x] The deploy drawer exposes all §3.2 controls, defaults to report-only, and calls out security-defaults changes.
- [x] A component test covers the drawer controls and plan rendering and fails without them.
- [x] No file outside `scope` is modified.
