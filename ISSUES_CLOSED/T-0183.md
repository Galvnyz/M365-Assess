# T-0183 — Baseline builder UI

## Report

EPIC-010 SPEC.md §3.3 defines Add/Edit Baseline with sidebar cards **Baseline Details**,
**Alerting**, **Setup Progress**, and **Baseline Summary**. The timeline steps are *Set a baseline
name → Assign tenants or groups → Add standards to at least one stage*, with **save disabled until
all three are done**. Stages are added/removed in order; each stage holds standards with
`logic: 'and'` and conditions, each condition individually removable (US-1, US-2). Alerting config
ties into EPIC-029 (prose).

Deliver the builder route, `BaselineTimeline`, `StageEditor`, and extend `baselinesApi.ts` wired to
T-0182. Stage/condition editing must not permit a non-`and` logic value.

## Acceptance

- [x] The three timeline steps render and gate the save button as specified.
- [x] Stages are ordered with add/remove; conditions are individually removable and only `and` logic is offered.
- [x] A test covers the builder interactions and fails without it; only theme tokens are used.
- [x] No file outside `scope` is modified.
