# T-0184 — Baseline state collectors and gated apply via EPIC-006

## Report

EPIC-010 SPEC.md §4.3: baselines reuse the same two-function shape CIPP uses (a **state
collector** reads current state, an **apply** step writes it). §8 states baseline apply steps are
tenant writes that route through **EPIC-006** exactly like Standards/Drift — **no
baseline-specific executor**, with licence/service/RBAC/scope/allowlist/audit all applying.

Deliver `Invoke-Baseline.ps1` and module wiring implementing the state-collector plus apply pair.
The apply path delegates every write to the EPIC-006 remediation contract (prose); a gate failure
skips the action and records why.

## Acceptance

- [x] A state collector returns the current state for a staged standard without writing.
- [x] Every apply write is routed through the EPIC-006 contract and audited; no direct write exists.
- [x] A gate failure skips the action with a recorded reason and does not write.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
