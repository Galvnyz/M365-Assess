# T-0809 — Baseline alignment: stage progress and run events

## Report

EPIC-010 SPEC.md §3.4 defines Baseline Alignment views (*every standard applicable to the
selected tenant*, *standards aggregated across tenants*, *baselines with assigned tenants and
stage progress*, *every recorded run event*) and §6 fixes
`GET /v1/baselines/{id}/alignment` (US-3, US-6). T-0188 delivered history/trend storage and
builders but no route file.

Deliver the alignment handler: per-stage progress across assigned tenants (from T-0185
rollouts), run events latest-first (from T-0188 history, append-only read), and trend points
for the T-0188 chart. Rows are filtered to the caller's tenant scope. Requires
`baselines.read`.

- [x] The endpoint returns per-stage progress, run events, and trend points.
- [x] Run events read newest-first with a limit; history is never mutated here.
- [x] Out-of-scope tenant rows are excluded; non-`baselines.read` callers are refused.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
