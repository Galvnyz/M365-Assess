# T-0288 — Named locations CRUD (IP and country)

## Report

EPIC-015 SPEC.md §3.4 defines CRUD for IP-based and country-based named locations and shows
which policies reference each; §6 fixes
`GET`/`POST`/`PATCH`/`DELETE /v1/tenants/{id}/ca/named-locations`; §5 notes named locations are
read live from Graph and not mirrored. §11.5 resolves the country-list representation to **Graph
country codes** rather than named presets.

Deliver `Set-CaNamedLocation.ps1` + entrypoint, the BFF CRUD routes behind the T-0108
gated-write seam, and `NamedLocationEditor`. Country lists are edited and validated as ISO 3166
alpha-2 codes matching Graph's `countriesAndRegions`; IP locations validate CIDR. The read side
computes the referencing policies (from the T-0281 policy set) so the UI can warn before deleting
a location in use. Each write is audited with before/after.

## Acceptance

- [x] IP and country named locations support create, edit, and delete with before/after audit.
- [x] Country lists are Graph country codes (ISO 3166 alpha-2) and IP entries validate CIDR.
- [x] The UI shows which policies reference a location and warns before deleting one in use.
- [x] Tests cover the route, worker, and editor and fail without them.
- [x] No file outside `scope` is modified.
