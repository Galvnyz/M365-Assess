# T-0244 — PIM role settings apply with plan preview

## Report

EPIC-013 SPEC.md §3.2 and §4.2 (US-3): applying a settings template is *load current role
settings → compare to template → plan preview → apply*, and the apply is a tenant write routed
through EPIC-006. §8 makes privileged writes the highest-risk category: confirmation,
before/after, and audit are mandatory.

Add an apply operation to `pim-settings-templates.ts` (preview mode returning the diff, apply
mode committing) and the `Set-PimRoleSettings.ps1` worker job plus `set-pim-role-settings.ps1`
entrypoint. Apply routes through the EPIC-006 gate (T-0104) and gated executor (T-0107) with
before/after captured and an `AuditEvent` written. A preview call performs no write. Extend
`portal.v1.yaml`.

## Acceptance

- [x] Preview returns the current-vs-template diff and writes nothing.
- [x] Apply confirms, routes through the EPIC-006 gate/executor, captures before/after, and audits.
- [x] A template with no target role cannot be applied (structured error).
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
