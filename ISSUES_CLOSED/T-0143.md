# T-0143 — Standards template CRUD, clone, and convert APIs

## Report

EPIC-008 SPEC.md §6 fixes the template endpoints: `GET`/`POST`/`PATCH`/`DELETE`
`/v1/standards/templates`, plus `POST /v1/standards/templates/{id}/clone`. §4.6 covers clone and
`Convert` between the `standards` and `drift` kinds where valid (US-1, US-8). §7 requires
`standards.read` for reads and `standards.write` for mutations, tenant-scoped via `UserScope`
(consumed through the shared RBAC seam from EPIC-001 T-0013 in prose; applying remediation inside
a standard is a separate EPIC-006 gate).

Deliver the route handlers and update the OpenAPI document to match exactly. Clone duplicates a
template (with assignments optionally); `Convert` validates that the change is legal for the
target kind.

## Acceptance

- [x] The five CRUD/clone endpoints are implemented and match the OpenAPI document.
- [x] `POST .../clone` produces an independent template; `Convert` rejects an invalid kind change.
- [x] Reads require `standards.read`, mutations `standards.write`, and out-of-scope tenants return a structured error.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
