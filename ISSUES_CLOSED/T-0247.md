# T-0247 — JIT admin/role templates CRUD

## Report

EPIC-013 SPEC.md §3.4 and §5 (US-6): templates define allowed roles, duration, justification,
and approval; row actions include `Edit template`. §5 defines `JitAdminTemplate` (`id`, `name`,
`allowedRoles[]`, `duration`, `justificationRequired`, `approvalRequired`).

Add the `JitAdminTemplate` entity via the next forward-only migration and a
`jit-templates-repository.ts`, then expose `GET`/`POST`/`PATCH`/`DELETE` `/v1/jit-templates` in
`jit-templates.ts`. A grant (T-0246) resolves its allowed roles, duration, and approval from
these templates; template changes never touch a tenant. Extend `portal.v1.yaml`.

## Acceptance

- [x] Templates CRUD persists allowed roles, duration, and the justification/approval flags.
- [x] A grant referencing a template outside its allowed roles is rejected.
- [x] Deleting a template with active grants is refused or reports the affected grants.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
