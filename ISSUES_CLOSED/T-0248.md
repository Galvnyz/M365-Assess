# T-0248 — Roles & Assignments page with PIM and templates tabs

## Report

EPIC-013 SPEC.md §3.1 (US-1, US-2): page title **Roles & Assignments** with tabs
**Assignments** / **PIM** / **Templates**; a table (Role · Principal · Type · Scope · Start ·
End · Status), filters (role, principal type, assignment type, scope), and row actions (`View`,
`Remove assignment`, `Activate`, `Extend`, `Set settings`). §3.1 also requires a P2-license gate
that **explains the requirement instead of failing** when PIM is unavailable. §3.2 adds the
settings-templates tab with `Edit`, `Clone`, `Apply to role`, `Delete`, and `Compare`.

Build the route, `RolesAssignmentsTable`, `PimSettingsTemplatesTab`, and a `P2GateNotice`, plus
a typed `rolesApi.ts` client for T-0241/T-0242/T-0243. `Activate`/`Extend`/`Set settings` route
to the schedule-request and settings-apply tickets; while those are absent render them disabled
with a reason. Use report theme tokens only.

## Acceptance

- [x] The three tabs render from their endpoints; filters narrow the assignments table.
- [x] Permanent vs eligible/active is visually distinct.
- [x] When P2 is absent the PIM tab shows `P2GateNotice` explaining the requirement, not an error.
- [x] Only report theme tokens/classes are used; no colour literals.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
