# T-0304 — Intune policy editor (settings editor + JSON mode)

## Report

EPIC-016 SPEC.md §4.1 requires create/edit via a **settings editor → plan preview → apply**.
§11.2 is resolved to a **full settings editor for common types with JSON editing for advanced
types**. The list pages (T-0303) expose `Edit`/`Add`.

Build the editor page, `IntunePolicyEditor`, `SettingsEditor` (structured controls for the
common Windows configuration and compliance settings), and `JsonSettingsEditor` (a validated raw
JSON editor for advanced types). The editor switches to JSON mode when the type has no structured
schema in the T-0301 registry, validates both modes against the registry, and submits through the
T-0302 plan-preview route to show the settings diff and assignment changes before apply.

## Acceptance

- [x] The editor renders structured controls for common types and a validated JSON editor for advanced types.
- [x] Submitting returns the plan preview (settings diff + assignments) before apply.
- [x] A component test covers both editor modes and validation and fails without them.
- [x] No file outside `scope` is modified.
