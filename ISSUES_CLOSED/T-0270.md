# T-0270 — Group usage report (membership, activity, ownerless/inactive)

## Report

EPIC-014 SPEC.md §3.5 defines the usage report: group activity — membership growth, inactive
groups, ownerless groups, guest counts. §6 fixes `GET /v1/tenants/{id}/groups/usage`. §11.3 is
resolved by adopting **report-only** ownerless/inactive group cleanup first (no bulk remediation
in this epic).

Deliver a read-only worker handler `Get-GroupUsage.ps1` + entrypoint and the `groups-usage` route
behind RBAC `groups.read`, plus the usage page and `GroupUsageReport` component. The report
computes membership counts over time from group activity, flags ownerless groups and groups with
no activity in a configurable window, and counts guests. The surface is read-only: ownerless and
inactive groups are listed with a link to the group, but no cleanup action is offered here;
bulk cleanup is deferred to a later ticket.

## Acceptance

- [x] `GET /v1/tenants/{id}/groups/usage` returns membership/activity, ownerless, inactive, and guest metrics.
- [x] The report is read-only; no cleanup write path is introduced.
- [x] Tests cover the route/handler and component and fail without them.
- [x] No file outside `scope` is modified.
