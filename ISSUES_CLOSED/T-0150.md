# T-0150 — Run-template-now, schedule set/clear, and variable substitution

## Report

EPIC-008 SPEC.md §4.3 and §6 define `Run template now` (`POST /v1/standards/templates/{id}/run`,
US-4) and `Set schedule` (`POST /v1/standards/templates/{id}/schedule`, clear or set). Run-now
enqueues immediately without waiting for the timer. §4.5 (US-7) requires `%name%` tokens in
settings to be substituted from `TenantVariable` values at run time, and an **unresolved variable
fails that standard loudly, not silently**; §9 flags variable-resolution failures as a risk.

Deliver the run-now/schedule routes and `standards-variables.ts`. Substitution reuses the tenant
variable values/helper owned by EPIC-002 (T-0027) in prose; this ticket wires the resolved values
into a standards run and enforces the fail-loud rule.

## Acceptance

- [x] `Run template now` enqueues a standards job without the schedule; setting/clearing a schedule updates the `Schedule` row.
- [x] `%variable%` tokens resolve from tenant variable values at run time.
- [x] An unresolved variable fails the affected standard loudly and is recorded, not silently ignored.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
