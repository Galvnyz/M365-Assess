# T-0267 — Group templates page, deploy wizard, and naming policy

## Report

EPIC-014 SPEC.md §3.2 defines the **Group Templates** page and deploy wizard: pick template →
target tenant(s) → variables → confirm; templates define group type, naming, owners, initial
members, GAL/delivery settings, and licensing. §11.2 requires a **template-driven naming policy
(prefixes/suffixes) plus conflict handling**, and §11.2 is resolved by defining that template here.

Build the page, `GroupTemplateTable`, `GroupTemplateForm`, and `DeployWizard` against the
T-0265/T-0266 APIs. The form includes a naming-policy section (prefix, suffix, and token
insertion validated against the allowed token set) and encodes conflict handling as an explicit
choice (block / append suffix) that is persisted with the template and honored by the T-0266
deploy. The wizard collects variables, shows the resolved plan, and renders per-target results.

## Acceptance

- [x] Templates can be created/edited/deleted and the naming policy (prefix/suffix/tokens, conflict behavior) is persisted.
- [x] The deploy wizard collects variables, shows the plan, and renders per-target results.
- [x] A component test covers template CRUD and wizard steps and fails without them.
- [x] No file outside `scope` is modified.
