# T-0306 — Intune template deploy worker and API

## Report

EPIC-016 SPEC.md §4.2 defines template deploy: resolve template + assignment mode → plan (policy
JSON + group actions) → apply; policies can be deployed to one or many tenants/groups and
**partial failures are reported**. §3.2 fixes the deploy-drawer inputs: template pick ·
assignment mode · policy state · overwrite switch · create-groups toggle, with a plan before
apply. §6 fixes `POST /v1/intune-templates/{id}/deploy`. §8 requires the target count to be shown
before apply when deploying to many tenants.

Deliver `Deploy-IntuneTemplate.ps1` + entrypoint and the BFF deploy route behind the T-0108
gated-write seam. The worker resolves the template and options into a plan (including groups to
create when the toggle is on), applies per target with before/after capture, and returns per-
target results with partial-failure detail. Overwrite conflicts are diffed against the live
policy. Every policy write is audited.

## Acceptance

- [x] The deploy route accepts the §3.2 options, shows the target count, and returns a plan before apply.
- [x] Deploy applies to one or many tenants/groups and reports per-target results including partial failures.
- [x] Overwrite is diffed against the live policy; each write is audited.
- [x] Tests cover the worker and route and fail without them.
- [x] No file outside `scope` is modified.
