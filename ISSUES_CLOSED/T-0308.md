# T-0308 — Reusable settings: list, templates, and sync

## Report

EPIC-016 SPEC.md §3.3 defines **Reusable Settings** — a list plus templates, where a `Sync`
action reconciles settings across policies (CIPP's `Sync-CIPPReusablePolicySettings`). §4.3
requires detecting policies that reference reusable settings, reconciling differences, and
applying updates with a **preview**. §5 adds `ReusableSettingTemplate` (`id`, `name`,
`settingsJson`). §6 fixes `GET`/`POST /v1/tenants/{id}/intune/reusable-settings` and
`POST .../reusable-settings/sync`. §11.3 is resolved by **defining the participating settings
types here** — enumerate the v1 sync scope (the common Windows configuration/compliance reusable
setting types in the T-0301 registry) and reject out-of-scope types. §9 warns of sync surprises,
mitigated by the preview diff.

Deliver `Sync-ReusableSettings.ps1` + entrypoint, the `ReusableSettingTemplate` migration/
repository, and the routes behind the T-0108 gated-write seam. Sync returns a per-setting
preview diff without writing; apply reconciles references and audits each change.

## Acceptance

- [x] The v1 sync scope enumerates the participating settings types and rejects out-of-scope types.
- [x] Sync returns a per-setting preview diff without writing; apply reconciles and audits.
- [x] Reusable setting templates persist and can be applied.
- [x] Tests cover the route, worker, and repository and fail without them.
- [x] No file outside `scope` is modified.
