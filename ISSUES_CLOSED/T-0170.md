# T-0170 — Executive drift report

## Report

EPIC-009 SPEC.md §3.4 (US-8) defines a branded PDF/HTML report (EPIC-005 templating) summarising
deviations, accepted items, and remediation status for management. §4.4 says it summarises counts
by state and top deviation categories, with progress over time drawn from EPIC-010's history once
baselines are in use.

Deliver the report route and the report component rendering counts by state and top categories.
The generated artifact uses the EPIC-005 report theme/branding (prose) and the trend series is a
documented follow-on from EPIC-010 (prose), not implemented here.
