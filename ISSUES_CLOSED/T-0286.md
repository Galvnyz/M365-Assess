# T-0286 — CA template deploy worker and API

## Report

EPIC-015 SPEC.md §4.2 defines template deploy: the operator picks a template and deploy options;
the portal resolves group/user handling and produces a plan (policy JSON + group actions); on
confirm, policies are created in the chosen state (**report-only recommended**); if *disable
security defaults* is chosen it is called out explicitly; each created policy is audited. §3.2
fixes the deploy-drawer inputs: group/user handling radio, policy state radio, overwrite switch,
disable-security-defaults switch, create-groups toggle; a plan is shown before apply. §6 fixes
`POST /v1/ca-templates/{id}/deploy`.

Deliver `Deploy-CaTemplate.ps1` + entrypoint and the BFF deploy route behind the T-0108
gated-write seam. The worker resolves the template and options into a plan (including any groups
to create), applies per policy with before/after capture, and audits each created policy. It
reuses the T-0282 validation so a template that would target `All users` + `Block` without a
break-glass exclusion is blocked unless the operator adds one. Overwrite conflicts are diffed
against the live policy before apply.

## Acceptance

- [x] The deploy route accepts the §3.2 options and returns a plan before apply.
- [x] Policies are created in the chosen state (report-only recommended) and each is audited.
- [x] Disable-security-defaults is surfaced explicitly; overwrite is diffed against the live policy.
- [x] The T-0282 hard-block and warning rules apply to deploy.
- [x] Tests cover the worker and route and fail without them.
- [x] No file outside `scope` is modified.
