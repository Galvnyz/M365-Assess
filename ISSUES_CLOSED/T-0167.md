# T-0167 — Bulk drift triage

## Report

EPIC-009 SPEC.md §3.1 lists bulk actions `Accept`, `Denied-Delete`, `Denied-Remediate` on selected
rows, and §6 fixes `POST /v1/drift/bulk` (US-7). Bulk triage applies the T-0165/T-0166 per-item
semantics across a selection within one tenant.

Deliver the bulk endpoint with all-or-nothing validation of selection membership, per-item audit
records, and a partial-result shape when some items are ineligible. `Denied-Delete` must carry the
same destructive confirmation token as the single-item path.

## Acceptance

- [x] `POST /v1/drift/bulk` applies accept/deny across a selection and returns per-item outcomes.
- [x] A `Denied-Delete` bulk request without the confirmation flag is rejected.
- [x] Every item in the batch is audited with the actor and reason.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
