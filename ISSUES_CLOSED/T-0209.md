# T-0209 — Users list, filters, row actions, and user reports

## Report

EPIC-011 SPEC.md §3.1 and §3.2 (US-1, US-8): the **Users** page title, primary `Add user`,
secondary `Add bulk` (CSV wizard); a table of Display name · UPN (mono) · Type · Licenses · MFA
state · Last sign-in · Status · Department; filters for status, type, license, MFA state,
department, and last sign-in age; row actions (`View`, `Edit`, `Reset password`, `Require
password change`, `Revoke sessions`, `Disable`/`Enable`, `Reset MFA`, `Manage licenses`, `Run BEC
check`, `Offboard`, `Delete`); bulk actions (license assign/remove, group add/remove, disable,
property patch); and an off-canvas row detail with a **More info** item. §3.2 adds the
inactive/guest/sign-in reports surface.

Build the route and `UsersTable` plus a typed `usersApi.ts` client for T-0201/T-0204, using only
report theme tokens and the shared DataTable/badge components. Row actions whose endpoints belong
to EPIC-012/013 (`Reset MFA`) render disabled with a reason until those tickets land.

## Acceptance

- [x] The table renders the §3.1 columns and each filter narrows the rows.
- [x] Row and bulk actions invoke the T-0204 actions; unavailable actions are disabled with a reason.
- [x] The reports view renders inactive, guest, and sign-in report data from the read API.
- [x] Only report theme tokens/classes are used; no colour literals.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
