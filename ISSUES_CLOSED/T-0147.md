# T-0147 — Standards template builder UI

## Report

EPIC-008 SPEC.md §3.2 specifies a `Wizard`/page with a timeline sidebar (*Set a name → Assign to
tenants → Add standards → Configure all standards*) mirroring CIPP's `CippStandardsSideBar`. The
per-standard accordion (`CippStandardAccordion` analogue) exposes actions **Report / Alert
(warn) / Remediate** plus an `autoRemediate` switch (US-2, US-3). The standard picker
(`CippBaselineStandardDialog` analogue) supports search, category, impact filter, sort, and a
card/list toggle; settings support `%variable%` tokens; an unsaved-changes guard blocks
navigation (US-7).

Deliver the builder route, `StandardAccordion`, `StandardPicker`, and extend `standardsApi.ts`.
The picker draws from the T-0144 catalog and flags licence-missing standards. `%variable%`
insertion is allowed here; resolution happens at run time (T-0150).

## Acceptance

- [x] The timeline and per-standard accordion render; action flags and the `autoRemediate` switch save.
- [x] The picker filters by search/category/impact and marks licence-missing standards.
- [x] An unsaved-changes guard blocks navigation; a test covers the builder interactions.
- [x] No file outside `scope` is modified.
