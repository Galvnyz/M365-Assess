# T-0249 — JIT admin, JIT templates, and schedule request UI

## Report

EPIC-013 SPEC.md §3.3 and §3.4 (US-4, US-5, US-6): page title **JIT Admins**; grant a user an
eligible/active admin role for a bounded window from a template; row actions `Grant`, `Revoke`,
`Extend`, `Edit template`. The **JIT Admin Templates** / **JIT Role Templates** pages define
allowed roles, duration, justification, and approval. The **schedule request** dialog requests
activation/assignment for a window and requires a justification, showing the pending state when
approval is configured.

Build the JIT admins route, `JitGrantsTable`, `JitTemplatesTab`, and `ScheduleRequestDialog`,
plus a typed `jitApi.ts` client for T-0244/T-0245/T-0246/T-0247. `Grant` requires a
justification where the template sets it; a pending request is shown as such. Use report theme
tokens only.

## Acceptance

- [x] The grants table renders active/expired grants and `Grant`/`Revoke`/`Extend` invoke the API.
- [x] The templates tab CRUD works and a template's allowed roles are enforced in the grant dialog.
- [x] A schedule request requires justification and renders `pending` when approval is configured.
- [x] Only report theme tokens/classes are used; no colour literals.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
