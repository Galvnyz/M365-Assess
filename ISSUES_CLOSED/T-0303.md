# T-0303 — Intune policy list pages

## Report

EPIC-016 SPEC.md §3.1 fixes three pages — **Configuration Policies**, **Compliance Policies**,
**App Protection Policies** — under nav *Intune → Device Management*, with the columns and
filters above and row actions `View`, `Edit`, `Clone`, `Assign`, `Compare`, `Export`, `Delete`.
The off-canvas detail shows settings and assignments, and a **Clone to template** action feeds
§3.2.

Build the three Next.js pages sharing `IntunePolicyTable` and `IntunePolicyDetailDrawer` against
the T-0301 list API via a typed `intuneApi.ts`. Each page is `kind`-parameterised; `Compare`
routes to T-0310 and `Clone to template` routes to the T-0305 template API (pre-filling the
form). Rendering follows the report theme.

## Acceptance

- [x] All three pages render their `kind` with the §3.1 columns, filters, and row actions.
- [x] The detail drawer shows settings and assignments; `Clone to template` is wired to the template API.
- [x] A component test covers rendering and filtering and fails without the component.
- [x] No file outside `scope` is modified.
