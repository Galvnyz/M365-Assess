# T-0163 — Drift detection worker (in-template mismatch + extra policy)

## Report

EPIC-009 SPEC.md §4.1 defines the drift run: the Drift system timer (EPIC-007, every 12 h +15 min
offset) enqueues a job per tenant; the job reads the tenant's full current state and the drift
template's expected state and computes deviations in **two directions** (CIPP `Get-CIPPDrift`):
**in-template mismatches** (a defined setting whose current value differs from expected) and
**extra policies** (a policy/resource present in the tenant but absent from the template). Each
deviation is upserted via T-0162.

Resolved §11.2 adopts **CA + Intune first** for the "extra policy" dimension (CIPP parity). Deliver
`Invoke-Drift.ps1` plus module wiring, emitting both deviation kinds through the T-0162 repository.

## Acceptance

- [x] A run detects in-template mismatches and extra policies as distinct `kind` values.
- [x] Extra-policy detection covers CA and Intune resource types in this version.
- [x] Deviations are upserted (T-0162) and none are resolved implicitly by a later run.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
