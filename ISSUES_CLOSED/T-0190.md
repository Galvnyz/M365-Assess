# T-0190 — Local baseline catalog

## Report

EPIC-010 SPEC.md §3.2 exposes a `Browse baseline catalog` action and §4.4 (US-8) loads prebuilt
baselines from a **local catalog plus the EPIC-039 community catalog**. §6 fixes
`GET /v1/baselines/catalog`. Resolved §11.4 adopts **local catalog first**; the community catalog
is deferred to EPIC-039.

Deliver the local catalog JSON and the browse endpoint. Each catalog entry carries a name and
staged standards that can seed a new baseline; the endpoint must not depend on EPIC-039 and must
clearly mark the community source as unavailable until that epic lands.

## Acceptance

- [x] `GET /v1/baselines/catalog` returns the local prebuilt baselines with their stages.
- [x] A catalog entry can seed a new baseline that passes the T-0182 save validation.
- [x] No EPIC-039 dependency is introduced; the community source is represented as absent.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
