# T-0302 — Intune policy CRUD worker and API

## Report

EPIC-016 SPEC.md §4.1 requires create/edit via a settings editor → **plan preview (settings diff
+ assignments)** → apply, with writes routed through EPIC-006; §6 fixes
`GET`/`POST`/`PATCH`/`DELETE /v1/tenants/{id}/intune/{kind}`. §8 requires assignment changes and
deletes to be confirmed and audited. §11.2 is resolved to a **full settings editor for common
types with JSON editing for advanced types**, so the CRUD API must accept both a structured
settings object and a raw JSON body and validate whichever is supplied against the T-0301
registry. §9 warns of policy misconfiguration impacting devices, mitigated by plan preview,
assignment mode, confirmation, and audit.

Deliver `Set-IntunePolicy.ps1` + entrypoint and the CRUD routes behind the T-0108 gated-write
seam. Create/edit return a plan containing the settings diff and assignment changes before
apply; delete requires confirmation naming the policy; assignment changes capture before/after.
Each write is audited.

## Acceptance

- [x] Create/edit return a plan with the settings diff and assignment changes; delete requires a naming confirmation.
- [x] The API accepts structured settings for common types and raw JSON for advanced types, validated against the registry.
- [x] Assignment changes capture before/after and each write is audited.
- [x] Tests cover the route and handler and fail without them.
- [x] No file outside `scope` is modified.
