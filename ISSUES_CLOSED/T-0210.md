# T-0210 — User detail, BEC review tab, and offboarding wizard UI

## Report

EPIC-011 SPEC.md §3.2 defines the user detail tabs (View · Edit · Exchange · OneDrive
shortcuts · Compromise remediation (BEC) · Conditional Access); the BEC tab renders the 11-check
review with per-finding remediate actions. §3.4 defines the **Offboarding wizard**: (1) tenant
selection including per-tenant offboarding defaults, (2) multi-user selection as
`displayName (UPN)`, (3) options toggles and mailbox access (full ± automap, send as, send on
behalf), (4) a 3-column confirmation summary plus **live job progress with per-step re-run**;
the page also lists past jobs filtered Running/Planned/Failed/Completed with an off-canvas task
detail drawer.

Build the detail route and `UserDetailTabs`, the `BecReviewTab`, the offboarding route and
`OffboardingWizard`, and a typed `offboardingApi.ts` client for T-0206/T-0207/T-0208. Use report
theme tokens only and reuse the ActionDialog/wizard primitives.

## Acceptance

- [x] The detail page renders the §3.2 tabs; the BEC tab shows the 11 checks and per-finding remediate actions.
- [x] The wizard collects tenant, users, options, and mailbox access and shows the confirmation summary before submit.
- [x] Live per-step progress renders and a failed step offers re-run; the past-jobs list filters by state.
- [x] Deletion and other destructive steps require explicit confirmation.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
