# T-0264 — Group create/edit form with raw dynamic-rule editor

## Report

EPIC-014 SPEC.md §4.1 requires create/edit with a **plan preview** and validation of dynamic
rules before apply; §11.4 resolves the dynamic rule editor to a **raw rule string with
validation** (not a guided builder). The list page (T-0263) exposes `Add group` and `Edit`.

Build the group form (`GroupForm`) used by the `new` page and the edit path: fields for type,
name/description, owners, initial members, GAL and delivery settings, and a `DynamicRuleEditor`
that edits the raw membership rule string, validates it client-side against the same rules the
T-0262 API enforces, and submits through the plan-preview route so the operator sees the diff
before confirm. Delete and convert confirmations route to the T-0262 API and render per-change
results. Keep the form self-contained against `groupsApi.ts`.

## Acceptance

- [x] Create and edit forms submit to the plan-preview API and render the returned diff.
- [x] The dynamic-rule editor edits a raw rule string and surfaces validation errors before apply.
- [x] A component test covers form submission and rule validation and fails without them.
- [x] No file outside `scope` is modified.
