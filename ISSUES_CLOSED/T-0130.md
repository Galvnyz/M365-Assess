# T-0130 — Custom Scripts UI (editor, versions, dry run)

## Report

EPIC-007 SPEC.md §3.3 defines the **Custom Scripts** page: table columns Name · Language
(PowerShell) · Author · Enabled · Alerts · Last run · Version; row actions `Edit`,
`View versions`, `Enable/Disable`, `Enable/Disable alerts`, `Run now`, `Delete`, `Save to
GitHub` (EPIC-039). The editor has a `ScriptContent` code area, a `MarkdownTemplate` area,
`TestParameters` JSON, and an **Explore data structure** helper; saving creates a new version.
§4.3 requires a dry run that shows output without side effects.

Deliver:

- The scripts route and `ScriptEditor` (content, markdown template, test parameters, structure
  helper) wired to T-0127, with save appending a version (T-0125).
- `ScriptVersionsDrawer` listing immutable versions and viewing a past version.
- Enable/disable (script and alerts) controls, and a `Run now` dry-run affordance showing the
  T-0128 rendered output.
- Component tests with a stubbed API.

Note: `Save to GitHub` belongs to EPIC-039 (prose cross-ref) and is rendered disabled/placeholder
until that epic exists.

## Acceptance

- [x] Creating and saving a script appends a version and updates the table.
- [x] Versions are listed and a past version is viewable but not editable.
- [x] `Run now` performs a dry run and renders the output via the markdown template.
- [x] Enable/Disable and Enable/Disable alerts persist.
- [x] No file outside `scope` is modified.
