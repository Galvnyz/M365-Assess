# T-0263 — Groups list page with filters and detail drawer

## Report

EPIC-014 SPEC.md §3.1 fixes the **Groups** page: nav *Identity Management → Administration →
Groups*, primary button `Add group`, a `DataTable` with Name · Type (M365/security/mail/
distribution/dynamic) · Membership · Owners · Hidden from GAL · Delivery mgmt · Dynamic rule,
the §3.1 filters, and row actions `View`, `Edit`, `Manage members`, `Manage owners`, `Hide from
GAL`, `Delivery management`, `Delete`, `Convert`. The off-canvas detail shows members, owners,
and settings.

Build the Next.js page and `GroupsTable` on the report theme (`cipp-ui-patterns.md` §2 tokens)
against the T-0261 list API via a typed `groupsApi.ts`; the detail drawer renders members and
owners from the same read API. Row-action handlers that mutate (edit/delete/GAL/delivery) link to
the tickets that build those dialogs; here they render and route. Type is distinguished with a
badge so §10's "types are distinguished" criterion is observable.
