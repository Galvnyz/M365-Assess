# T-0307 — Intune templates page and deploy drawer

## Report

EPIC-016 SPEC.md §3.2 fixes the **Policy Templates** page and the deploy drawer with CIPP
`CippPolicyDeployDrawer` parity: template pick · assignment mode · policy state · overwrite
switch · create-groups toggle, showing a plan before apply. §3.1's `Clone to template` action
feeds this page.

Build the page, `IntuneTemplateTable`, and `IntuneDeployDrawer` against the T-0305/T-0306 APIs.
The drawer collects the §3.2 options, presents the target tenant/group count before apply, and
renders the plan and per-target results from the deploy route.

- [x] The deploy drawer exposes all §3.2 controls and shows the target count and plan before apply.
- [x] A component test covers the drawer controls and plan rendering and fails without them.
