# T-0284 — Conditional Access policy editor

## Report

EPIC-015 SPEC.md §3.3 defines the full policy editor: conditions (users/groups/roles, apps,
platforms, locations, client apps, risk, device state) and grant/session controls. The editor
**validates against the same checks the `CAEvaluator` uses** and warns on known-weak
configurations before save; §4.1 requires a plan preview (JSON diff) before apply; §4.3 requires
the `All users`-without-admin-exclusion warning with a break-glass exclusion picker.

Build the editor page, `CaPolicyEditor`, and `CaConditionBuilder` (plus a grant/session controls
section) against the T-0282 API. Before save the editor calls the validation endpoint, renders
warnings and any hard-block errors inline, offers a break-glass account/group exclusion picker,
and shows the JSON diff returned by the plan-preview route. New policies render with the
report-only default pre-selected (§11.1).

## Acceptance

- [x] The editor covers all §3.3 conditions and grant/session controls and submits to the plan-preview API.
- [x] Validation warnings and the `All users` + no-exclusion warning render; hard-block errors prevent apply.
- [x] A break-glass exclusion picker is available and the JSON diff is shown before apply.
- [x] A component test covers validation and save and fails without the editor.
- [x] No file outside `scope` is modified.
