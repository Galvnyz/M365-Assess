# T-0112 — Remediation plan page

## Report

EPIC-006 SPEC.md §3.2: nav *Tenant Administration → Remediation*, title **Remediation Plan —
<run/tenant>**. A primary `Generate plan` button (POST, confirm dialog), secondary `Export`
(JSON/MD/CSV), a summary `.kpi-strip` (total actions, automated, manual, gated/skipped), and a
`DataTable` (`cipp-ui-patterns.md` §2) with columns Check ID (mono), Finding, Severity
(`sev-badge`), Mode (`auto`/`manual`), Action state (`status-badge`), License, Target. Filters:
mode, severity, collector, state, "eligible only". Row actions: `View plan`, `View instructions`,
`Apply` (only when state `planned` and the caller has `remediation.apply`, disabled otherwise),
`Skip`; a row detail drawer shows command, before/after, and audit trail.

Build the page and `RemediationPlanTable` with the typed `remediationApi.ts` client (extending
the file from T-0111). Reuse the shared DataTable/badge/kpi components and the report theme.
`Generate plan` and `Export` call the T-0105 endpoints.

## Acceptance

- [x] Page renders the KPI strip and the full DataTable from a plan; filters narrow the rows.
- [x] `Apply` is enabled only for `planned` actions when the caller holds `remediation.apply`; otherwise disabled.
- [x] `Generate plan` and `Export` (JSON/MD/CSV) are wired to the API.
- [x] A test covers the change and fails without it.
- [x] No file outside `scope` is modified.
