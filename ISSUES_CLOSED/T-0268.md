# T-0268 — Bulk membership and owners, end to end

## Report

EPIC-014 SPEC.md §3.3 defines the bulk-membership `Wizard`: select group → choose add/remove →
select users (or CSV) → **preview diff** → apply, with per-row results. §4.3 requires batching and
per-change auditing; §6 fixes `POST .../members/bulk` and `POST .../owners/bulk`; §8 requires
confirmation for bulk membership and per-change audit records. The §9 risk is accidental mass
membership change, mitigated by preview, per-row results, and audit.

Deliver the worker handler `Invoke-GroupMembershipBulk.ps1` + entrypoint, the BFF routes, and the
`BulkMembershipWizard` UI. The preview endpoint computes the add/remove diff (resolving the user
references from the T-0261 read model / EPIC-011 user source) without writing; apply performs the
batched changes through the gated-write seam (T-0108) and returns a per-row result (added,
removed, skipped, failed). Both members and owners share the handler.

## Acceptance

- [x] The preview endpoint returns the exact add/remove diff without writing.
- [x] Apply batches changes and returns per-row results; each change is audited.
- [x] The wizard supports manual selection and CSV upload and renders the preview and per-row results.
- [x] Tests cover the route and component and fail without them.
- [x] No file outside `scope` is modified.
